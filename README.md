# Claude Code mods by ilovepixelart

One marketplace for every mod I publish. Add it once, then install any of them by name.

```
/plugin marketplace add ilovepixelart/claude-code-mods
/plugin install pass-or-bust@ilovepixelart
```

Each entry is pinned to a released version, so you get exactly what was tested and released. `claude plugin update <mod>@ilovepixelart` picks up the next release once it is listed here.

## Mods

| Mod | What it does | Release |
| --- | --- | --- |
| [pass-or-bust](https://github.com/ilovepixelart/pass-or-bust-mod) | Slots for your test runs. The reels spin while Claude runs the tests and stop on the real result. Fake credits only. | [0.1.0](https://github.com/ilovepixelart/pass-or-bust-mod/releases/tag/pass-or-bust--v0.1.0) |

Requires Claude Code 2.1.287 or later. Read a mod's source before you install it: mods run inside Claude Code on your machine.
